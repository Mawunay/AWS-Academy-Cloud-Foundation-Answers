# Module 8 Knowledge Check


### **Q1.**
You are designing an eCommerce web application that will scale to hundreds of thousands of concurrent users.  
Which database technology is best suited to hold the session state in this example?

**Answer:**  
**Amazon DynamoDB**

### **Q2.**

Which of the following operations should you use?

**Scan**

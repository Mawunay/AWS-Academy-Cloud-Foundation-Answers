# Module 6 Knowledge Check


### **Q1.**
Why is AWS more economical than traditional data centers for applications with varying compute workloads? _(Select the best answer)_

**Answer:**  
**Amazon EC2 instances can be launched on demand when needed**

---

### **Q2.**
If your project requires monthly reports that iterate through very large amounts of data, which Amazon Elastic Compute Cloud (Amazon EC2) purchasing option should you consider? _(Select the best answer)_

**Answer:**  
**Scheduled Reserved Instances**

---

### **Q3.**
What is included in an Amazon Machine Image (AMI)? _(Select the best answer)_

**Answer:**  
**All of the above**

---

### **Q4.**
Which Amazon Elastic Compute Cloud (Amazon EC2) feature ensures your instances will not share a physical host with instances from any other AWS customer? _(Select the best answer)_

**Answer:**  
**Dedicated Instances**

---

### **Q5.**
Which of the following services is a serverless compute service in AWS? _(Select the best answer)_

**Answer:**  
**AWS Lambda**

---

### **Q6.**
What is the service provided by AWS that enables developers to easily deploy and manage applications in the cloud? _(Select the best answer)_

**Answer:**  
**AWS Elastic Beanstalk**

---

### **Q7.**
Your web application needs four instances to support steady traffic all the time. On the last day of the month, the traffic triples. What is the most cost-effective way to handle this pattern? _(Select the best answer)_

**Answer:**  
**Run four Reserved Instances constantly, then add eight On-Demand Instances on the last day of each month**


---
